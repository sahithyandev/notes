Non-parametric statistical tests used to analyze categorical data. Used to evaluate whether observed frequencies differ significantly from expected frequencies.

## Assumptions

- Observations are independent.
- Categories are mutually exclusive and exhaustive.
- Expected frequencies ≥ 5 (combine small ones if needed).
- Sample size is sufficiently large.

## Types

2 types:

- Test of Independence
- Goodness-of-Fit test
