If there are $n$ boxes and $m$ pigeons (where $m > n$), then at least one box must contain $\lceil \frac{m}{n} \rceil$ pigeons.

For a graph with $n \ge 2$ vertices, there exist 2 vertices with the same degree.

<Note title="Proof Hint">

- There are $n$ vertices
- Possible values for degree from $0$ to $n-1$
- $0$ and $n-1$ cannot occur at the same time.

</Note>
