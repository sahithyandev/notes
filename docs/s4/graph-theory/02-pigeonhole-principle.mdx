If $m$ objects are placed into $n$ containers where $m > n$, at least 1 container holds $\ge \lceil \frac{m}{n} \rceil$ objects.

## Graph Degree Corollary

For any simple graph with $n \ge 2$ vertices, at least 2 vertices share the same degree.

<Note title="Proof Hint">

- Possible degree values range from $0$ to $n-1$ ($n$ values total)
- Degrees $0$ and $n-1$ cannot both occur (a vertex connected to all others cannot coexist with an isolated vertex)
- So at most $n-1$ distinct degree values exist for $n$ vertices
- By pigeonhole, 2 vertices share a degree

</Note>

## Applications in Graph Theory

### Paths in Dense Graphs

In any graph where every vertex has degree $\ge \lceil \frac{n}{2} \rceil$, a Hamiltonian path exists. The pigeonhole argument shows that any 2 non-adjacent vertices share enough neighbors to force connectivity.

### Ramsey Numbers

Ramsey theory uses pigeonhole to prove monochromatic substructures must exist in large enough graphs. The classic result: in any 2-coloring of the edges of $K_6$, there is a monochromatic triangle.

<Note title="Proof Hint">

- Pick any vertex $v$ in $K_6$. It has $5$ edges.
- By pigeonhole, at least $3$ edges from $v$ share the same color (say red).
- Call the 3 endpoints $a, b, c$.
- If any edge among $a, b, c$ is red, that edge plus 2 red edges from $v$ form a red triangle.
- If no edge among $a, b, c$ is red, all 3 are blue, forming a blue triangle.

</Note>
