## Rooted Trees

A tree where a vertex is designated as the _root_ vertex.

### Height

Length of the longest path from the root.

### Level

For a given vertex $v$, length of the simple path from the root to $v$.

### Parent

For a given vertex $v$, its parent vertex is the unique vertex $u$ where $\text{level}(u) \lt \text{level}(v)$ and there is an edge between $u$ and $v$.

### Child

For a given vertex $v$, $u$ is a child of $v$ **iff** $v$ is the parent of $u$.

### Siblings

Vertices with the same parent.

### Ancestors

For a given vertex $v$, all vertices in the path from the root to $v$, excluding $v$ and including the root.

### Descendants

For a given vertex $v$, all vertices that have $v$ as their ancestor.

### Leaf

In a rooted tree, a leaf does not have any children.

### Internal vertices

Vertices that have children.

### Sub-rooted tree

Suppose $a$ is a vertex in a tree. Then the sub-tree with $a$ as its root is the sub-graph of the
tree consisting of $a$ and its descendants and all edges incident to these descendants.

### m-ary tree

When all internal vertices has $\le m$ children.

### Full m-ary tree

When all internal vertices have exactly $m$ children.

A full $m$-ary tree with:
- $n$ vertices has $i = (n−1)/m$ internal vertices and $l = [(m−1)n + 1]/m$ leaves.   
- $i$ internal vertices has $n = mi + 1$ vertices and $l = (m−1)i + 1$ leaves.   
- $l$ leaves has $n = (ml−1)/(m−1)$ vertices and $i = (l−1)/(m−1)$ internal vertices.

<Note title="Proof Hint">

Use the following equations:
- $i+l=n$
- $m+(i-1)(m+1)+l = 2(n-1)$

</Note>

There are at most $m^h$ leaves in an $m$-ary tree of height $h$.

<Note title="Proof Hint">

Use induction on level.

</Note>
