A simple graph where every pair of vertices is adjacent. Denoted by $K_n$ where $n$ is the number of vertices.

Contains the maximum number of edges for a simple graph.

$$
|E| = \frac{n(n-1)}{2}
$$

<Note title="Proof Hint">

- Suppose there are $n$ vertices.
- There are $\frac{n(n-1)}{2}$ vertex pairs.
- 1 edge exist for a pair.

</Note>
