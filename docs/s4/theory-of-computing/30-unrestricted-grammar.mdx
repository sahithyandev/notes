Aka. phrase-structure grammar. A 4-tuple $G = (V, \Sigma, S, P)$ where:

- $V$ — non-terminals
- $\Sigma$ — terminals
- $S$ — start symbol
- $P$ — productions $\alpha \to \beta$ where $\alpha, \beta \in (V \cup \Sigma)^*$ and $\alpha$ contains $\geq 1$ non-terminal
  $V$ and $\Sigma$ are disjoint.

A relaxation over CFGs where, on LHS of productions, more than 1 non-terminals may occur.

For any recursively-enumerable language $L$, there exists an unrestricted grammar $G$ generating $L$.

For any unrestricted grammar $G$, there exists a Turing machine $T$ that accepts the same language.

## Context-Sensitive Grammar

Aka. CSG. An unrestricted grammar where every production $\alpha \to \beta$ satisfies $|\beta| \geq |\alpha|$.

- Equivalent form: $\alpha A \beta \to \alpha X \beta$ where $X \neq \Lambda$, $A \in V$, $\alpha, \beta, X \in (V \cup \Sigma)^*$.

## Context-Sensitive Language

Aka. CSL. Languages generated by a CSG.

A language is _context-sensitive_ **iff** it can be generated by a grammar in which every production has the form:

$$
αAβ → αXβ
$$

where $α, β$ and $X$ are strings of non-terminals and/or terminals, $X ≠Λ$ and $A$ is a non-terminal.

## Linear-Bounded Automata

Aka. LBA. A nondeterministic Turing machine with limited-length tape. Length bounded linearly by input length. Head cannot move beyond defined bounds. Lies between PDA and TM in computational power.

If $L$ is a context-sensitive language then there exists an LBA accepting $L$.

If there exists a LBA accepting $L \subseteq \Sigma^*$ then there exists a CSG generating $L - \{\Lambda\}$.
