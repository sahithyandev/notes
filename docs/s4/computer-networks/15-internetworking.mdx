Internetworking connects different networks that may use different technologies.

Challenging because:

- Different protocols
- Different addressing schemes
- Different packet sizes
- Security differences
- QoS differences

## Interconnection Methods

Networks can be interconnected at different OSI layers.

| Layer       | Device               |
| ----------- | -------------------- |
| Physical    | Repeaters, hubs      |
| Data Link   | Bridges, switches    |
| Network     | Routers              |
| Transport   | Transport gateways   |
| Application | Application gateways |
