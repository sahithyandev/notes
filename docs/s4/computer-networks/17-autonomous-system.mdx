A collection of IP networks and routers under the control of one administrative entity.

- Identified by a unique AS Number (ASN), assigned by IANA.
- Contains multiple routers and uplinks to other ASes.
- The boundary between AS domains defines the boundary between Intra-AS and Inter-AS routing.

## Routing

### Intra-AS

<Aka>Interior Gateway Protocol (IGP)</Aka>. Operates within a single AS.

### Inter-AS

<Aka>Exterior Gateway Protocol (EGP)</Aka>. Operates between different ASes.

| Scope    | Principle       | Protocols   |
| -------- | --------------- | ----------- |
| Intra-AS | Distance Vector | RIP         |
| Intra-AS | Link State      | OSPF, IS-IS |
| Inter-AS | Path Vector     | BGP         |

See [Routing](/s4/computer-networks/routing) for algorithm details.
