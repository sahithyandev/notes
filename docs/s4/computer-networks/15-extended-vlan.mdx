VLAN can be extended to different geographically separated sites.

Used when an organization's head office and branches must be in the same VLAN.

### Layer 3 VPN (Site-to-Site IPsec)

**Layer 3 extension** — routes traffic between subnets across a VPN tunnel. VLANs remain local to each site. Inter-VLAN routing occurs at Layer 3.

- IPsec tunnel between firewalls/routers.
- Different subnets per site per VLAN.
- Does **not** extend Layer 2 broadcasts.
- Most common deployment model.

Examples:

- VLAN 10 (HR): `192.168.10.0/24` (HO), `192.168.110.0/24` (branch)
- VLAN 20 (Finance): `192.168.20.0/24` (HO), `192.168.120.0/24` (branch)

### Layer 2 VPN (True VLAN Extension)

**Layer 2 extension** — emulates a single LAN across sites. Same subnet at both ends. Required when applications depend on Layer 2 adjacency.

Technologies:

- **MPLS VPLS** (Virtual Private LAN Service) — Layer 2 multipoint; emulates shared LAN via MPLS.
- **EoMPLS** (Ethernet over MPLS) — encapsulates Ethernet frames inside MPLS labels.
- **L2TPv3** — IETF protocol for Layer 2 tunneling.

VPLS issues:

- Same broadcast domain across WAN.
- Risk of broadcast storms.
- Spanning Tree Protocol (STP) must operate across WAN.

### VLAN Tag Flow Over VPN

**802.1q frame** — carries VLAN tag (TPID + TCI) in Ethernet header.

Encapsulation over IPsec:

1. Switch applies 802.1q VLAN tag.
2. Switch forwards frame to router/firewall.
3. Router/firewall wraps entire Ethernet frame in IPsec (ESP header added).
4. Packet sent over Internet: `[IP header][ESP header][Encapsulated Ethernet frame]`
5. Remote site decapsulates.

### VXLAN Over IPsec

**VXLAN** (Virtual eXtensible Local Area Network) — Layer 2 over Layer 3 using UDP.

- 24-bit **VNID** (VXLAN Network Identifier) → 16 million logical networks.
- Overcomes 4096-VLAN limitation of 802.1q.
- No STP bottlenecks.
- UDP port 4789.

**VTEP** (VXLAN Tunnel Endpoint) — device performing VXLAN encapsulation/decapsulation. Hardware switch or software virtual switch.

VXLAN process:

1. Switch applies 802.1q tag.
2. Frame forwarded to VTEP.
3. VTEP applies VXLAN encapsulation over UDP.
4. IPsec encryption applied on UDP payload.
5. Transmitted over Internet.

Result: tunnel within a tunnel. Overlay network (VNIs) runs above underlay transport network (IP).

Advantages:

- Scalable — 16 million VNIs.
- Suitable for data centers.
- Runs over standard IP networks.

### Design Issues

**Broadcast traffic** — ARP floods, DHCP broadcasts, STP BPDUs propagate across WAN when extending Layer 2.

**Latency** — WAN delay impacts Layer 2 protocols sensitive to timing.

**MTU** — VPN encapsulation adds overhead; risk of fragmentation. Requires MTU tuning.

**Security** — IPsec encryption required. ACL filtering recommended.

### L2 vs L3 VPN Comparison

| Feature             | L3 VPN | L2 VPN |
| ------------------- | ------ | ------ |
| Same subnet         | No     | Yes    |
| Broadcast extension | No     | Yes    |
| Scalability         | High   | Medium |
| Risk level          | Low    | Higher |
| Complexity          | Medium | High   |

### Best Practices

- Prefer Layer 3 routing between sites.
- Do not stretch VLANs unless required.
- Preferred technologies: OSPF/BGP over IPsec, MPLS L3VPN, SD-WAN.

Use Layer 2 extension only for:

- VM mobility requirements.
- Legacy application Layer 2 dependencies.
- Data center interconnect.
