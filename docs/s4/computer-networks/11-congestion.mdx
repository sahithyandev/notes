A network is said to be _congested_ when the offered traffic approaches or exceeds the network capacity.

Congestion causes:

- Increased delay
- Packet loss
- Reduced throughput

## Congestion Control

### Open Loop Control

Prevents congestion before it occurs. Network state is not monitored. Typically implemented at transport or network layer.

### Closed Loop Control

Detects and reacts to congestion.

Steps:

1. Monitor network conditions
2. Inform relevant nodes
3. Take corrective action
