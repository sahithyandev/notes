An IoT solution consists of interconnected hardware and software components that collect data, transmit it, and process it for decision making.

The IoT architecture is structured in three layers:

**Edge Layer** — the physical layer. Contains sensors, actuators, and hardware interfaces. Characteristics: low computing power, low energy consumption, lower reliability per unit, but deployed in large volumes. Responsible for raw data collection and direct physical-world interaction. This is where embedded processing happens.

**Fog Layer** — the intermediate processing layer. Sits between edge and cloud. Handles local computation, local decision-making, and data pre-processing. The purpose of the fog layer is to reduce latency (processing locally rather than sending everything to the cloud) and to reduce bandwidth load on the network. It handles tasks that require fast responses but don't need the full compute resources of cloud infrastructure.

**Cloud Layer** — the back-end infrastructure (Google Cloud, AWS, Azure, Huawei Cloud, etc.). Capabilities: high-power compute, large-scale data storage, big data analytics, AI/ML workloads, computer vision, voice recognition, NLP. Cloud is where long-term data storage, training of models, and high-complexity analytics occur. Not suitable for latency-sensitive decisions.

The full component chain reads: Sensors → Actuators → H/W Interfaces → Microcontrollers → Software → Communication → Cloud/Central Servers → Big Data Analytics → AI/ML.

## Major Components

### Device Layer

Aka. edge layer. Hardware components embedded in physical devices. Includes:

- Sensors  
  Take inputs from the environment and convert them into data.
- Actuators  
  Modify the environment based on commands from the system.
- Hardware interfaces
- Microcontrollers
- Embedded software

### Communication Layer

Aka. fog layer. Responsible for transmitting data between devices and servers.

Examples:

- Wireless communication protocols
- Internet connectivity
- Networking infrastructure

### Processing and Cloud Layer

Processes and analyzes IoT data.

Technologies:

- Cloud servers
- Big data analytics
- Artificial Intelligence / Machine Learning
- Data analytics platforms (e.g., Google Cloud, AWS, Azure)

#### Edge Processing

Where data is processed at the IoT devices (hence _edge_) of the network, close to the source of data generation. Computing power is very limited. Reduces latency and bandwidth usage by processing data locally instead of sending it to the cloud.

#### Fog Processing

Where data is processed at intermediate nodes between the edge and the cloud. These nodes can be local servers, gateways, or routers that provide additional computing resources. Slightly more computing power than edge devices. Reduces latency and bandwidth usage compared to sending everything to the cloud.
