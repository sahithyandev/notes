## Supervisory Circuits

Independent hardware that monitors the main processor.

Monitors:

- Clock speed
- Temperature
- RAM operation
- System health

Can:

- Restart the processor
- Shut down the system
- Generate alarms

## Watchdog Timer

One of the most important supervisory features.

A counter continuously increments. The running program must periodically reset it. If not reset, the counter reaches its limit and the processor automatically restarts.

Detects:

- Infinite loops
- Software crashes
- Unresponsive programs

<Note>

A common bug is repeated restarts caused by omitting the watchdog reset in program code.

</Note>
