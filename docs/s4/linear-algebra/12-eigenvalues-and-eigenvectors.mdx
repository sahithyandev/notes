Let $T: V\rightarrow V$ over $F$. $\lambda \in F$ and $v \in V$ satisfying $T(v)=\lambda v$ are called an eigenvalue and a corresponding eigenvector of $T$ respectively.

Here for any $\lambda$, $v=\underline{0}$ is a trivial solution. Usually only non-trivial solutions are mentioned.

### Properties

**If** $\lambda$ is an eigenvalue of $A$ **then** $\lambda^{-1}$ is an eigenvalue of $A^{-1}$.

<Note title="Proof Hint">

- Assume $A$ has an inverse
- $\lvert A - \lambda I \rvert = 0$
- Multiply both sides by $A^{-1}$ from left
- Rearrange to get $\lvert A^{-1} - \lambda I \rvert = 0$

</Note>

**If** $A^{-1} = P^{-1} A P$ for some matrix $P$ **then** $A$ and $A^{-1}$ has the same set of eigenvalues.

<Note title="Proof Hint">

- Assume $A$ has an inverse
- $\lvert A^{-1} - \lambda I \rvert = 0$
- Substitute for $A^{-1}$ and $I = P^{-1}P$
- Simplify to get $\lvert A - \lambda I \rvert = 0$

</Note>

Product of the eigenvalues is equal to the [determinant](/s1/mathematics/matrices/determinant).

<Note title="Proof Hint">

- $f(\lambda) = \lvert \lambda I -  A \rvert = \prod_{i=1}^{n} (\lambda - \lambda_i) = \lambda^n + (-1)^n (\lambda_1+\lambda_2+\dots+\lambda_n)\lambda^{n-1} + O(\lambda^{n-2})$
- $f(0) = \lvert - A \rvert = (-1)^{n} \lvert A \rvert = (-1)^{n}\big(\prod_{i=1}^{n} \lambda_i\big)$
- $\lvert A \rvert = \prod_{i=1}^n \lambda_i$

</Note>

Sum of the eigenvalues is the equal to the [trace](/s1/mathematics/matrices/trace) of the matrix.

<Note title="Proof Hint">

- Expand $\lvert \lambda I - A\rvert$ to $\prod_{i=1}^n (\lambda - a_{ii}) = \lambda^{n} + (a_11+a_22+\dots+a_nn)\lambda^{n-1} + O(\lambda^{n-2})$
- Use the above prove's hint and compare the coefficients of $\lambda^{n-1}$

</Note>

[Cayley Hamilton theorem](/s1/mathematics/matrices/cayley-hamilton-theorem) can be used to find the inverses and higher power matrices efficiently.

<Note title="Proof Hint">

- Suppose $ f(\lambda)=\sum\_{i=0}^{n} a_i\lambda^{i} $
- Use [the below property of adjoint](/s1/mathematics/matrices/adjoint#properties) on $\lambda I - A$:  
  $A\cdot\text{adj}(A) = \lvert A\rvert I$
- Use $\text{adj}(\lambda I - A) = \sum_{i=1}^n B_{n-i}\lambda^{n-n}$
- Expand both sides and equate coefficients
- Multiple $i$th equation by $A^{n-i+1}$ (do this for all)
- Sum all the equations

</Note>

If $\lambda$ is an eigenvalue of $A$, then $\lambda^n$ is an eigenvalue of $A^n$ where $n \in \mathbb{Z} $.

<Note title="Proof Hint">

For $n \in \mathbb{Z}^+$:

- Start with $Av = \lambda v$
- Multiply $A$ from the left repeatedly
- Subtitute $\lambda v$ for $Av$

Obvious for $n=0$. Already proven for $n=-1$. Use the above method and multiply from left.

</Note>

If $\lambda$ is an eigenvalue of $A$, then $p(\lambda)$ is an eigenvalue of $p(A)$ where $p$ is any polynomial which takes in an number or a matrix.

<Note title="Proof Hint">

Use the above conclusion for a polynomial.

</Note>

## Eigenspace

For a given $\lambda \in F$, the set of corresponding eigenvectors.

$$
V_\lambda = \set{ v\in V | T(v)=\lambda v }
$$

An eigenspace is a subspace of $V$.

<Note title="Proof Hint">

- $V_\lambda$ is non-empty (includes $\underline{0}$)
- $V_\lambda \subseteq V$
- $V_\lambda$ is closed under vector addition and scalar multiplication

</Note>

Basis of an eigenspace is usually given as the eigenvectors.

For any eigenvalues $\lambda_1$ and $\lambda_2$,

$$
V_{\lambda_1} \cap V_{\lambda_2} = \set { \underline{0} }
$$

## Minimal Polynomial

For $A \in F^{nn\times n}$, $m(x)$ of $A$ is such that:

- $m(x)$ is monic (i.e. the leading coefficient is 1) (which implies $m(x) \not\equiv 0$)
- $m(A) = 0$
- **If** $h(x) \not\equiv 0$ and $h(A)=0$ **then** $\text{deg}(h) \ge \text{deg}(m)$

**If** $f(\lambda)=0$ **then** $m(\lambda)=0$.

<Note title="Proof Hint">

- $f(\lambda)=0$ implies $\lambda$ is an eigenvalue
- $Av=\lambda v$
- Use one of the above theorems to $m(A)v = m(\lambda)v$ which implies $0 = m(\lambda) v$ which implies $m(\lambda)=0$

</Note>

$m(x)$ divides $f(x)$.

<Note title="Proof Hint">

- By [Cayley-Hamilton theorem](/s1/mathematics/matrices/cayley-hamilton-theorem), $f(A)=0$
- Minimal polynomial $m$ has the least degree $\text{deg}(m) \lt \text{deg}(f)$
- So $f(x) = p(x)m(x) + q(x)$ where $\text{deg}(q) \lt \text{deg}(m)$
- Subtitute $A$ for $x$, $q(A)=0$
- The only possibility is $q(x) \equiv 0$
- Which means $f(x) = p(x)m(x)$

</Note>

**If** $m(\lambda)=0$ **then** $f(\lambda)=0$.

As $m(x)$ divides $f(x)$, they both have the same basic factors with different powers.

### Minimal Multiplicity

The powers in $m(x)$. Denoted as $m_\lambda$.

$$
n \ge a_\lambda \ge m_\lambda \ge 1
$$

## Diagonalization

[Basics for Diagonalization](/s1/mathematics/matrices/diagonalization) is already covered in 1st semester.

The following statements are equivalent:

- $A \in C_{n\times n}$ is diagonalizable
- $a_\lambda = g_\lambda$
- $m_\lambda = 1$
- Eigenvectors form a basis for $C_n$
