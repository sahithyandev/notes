Factorization that works for all matrices.

$$
A = V \Sigma U^H
$$

Here:

- $U$, $V$ are unitary
- $\Sigma$ has singular values on diagonal.

Singular values are square roots of eigenvalues of $A^HA$ (or $AA^H$).
