A [classical cipher](/s5/computer-security/ciphers#classical-ciphers), from the pre-computer era.

Encryption replaces each letter in the alphabet with the letter at its mirrored position, counting from the opposite end.

$$
c = 25 - m \mod 26
$$

Here $m$ is the plaintext letter, encoded as an integer 0 (a) to 25 (z).

<Note>

Atbash has no key: a always maps to z, b to y, and so on. Encryption and decryption are the same operation.

</Note>

Originally devised for the Hebrew alphabet, then applied to Latin and other alphabets.

You can find an implementation of the Atbash cipher in [sahithyandev/ciphers](https://github.com/sahithyandev/ciphers/blob/main/src/atbash-cipher.c).

### Breaking the Atbash Cipher

There is no key to search: the mapping is fixed, so recovering the plaintext is a single substitution away once Atbash is suspected.
