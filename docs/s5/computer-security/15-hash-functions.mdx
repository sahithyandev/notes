A hash function $H$ maps a message $m$ of any length to a fixed $n$-bit digest $H(m)$. It is public, keyless, and deterministic.

Cryptographic uses:

- Padding  
  Randomised padding schemes such as OAEP mix message bits with hash output before public key encryption.
- Signing  
  A signature is computed over $H(m)$, so it covers an input of any length at fixed cost.
- Key derivation  
  A raw secret is hashed to produce a symmetric key of the required length with no algebraic structure.

## Properties

Each property is stated as work an attacker cannot afford. Generic cost is the effort with no weakness in $H$, over an $n$-bit digest.

### Preimage Resistance

Given a digest $d$, an attacker cannot find any $m$ with $H(m) = d$. Generic cost about $2^n$.

### Weak Collision Resistance

Given a fixed message $m$, an attacker cannot find a different $m'$ with $H(m') = H(m)$. Also called second-preimage resistance. Generic cost about $2^n$.

### Strong Collision Resistance

An attacker cannot find any pair $m \neq m'$ with $H(m) = H(m')$, both of their choosing. Generic cost about $2^{n/2}$.

Among $2^{n/2}$ random messages a repeated digest is already likely, since the number of pairs grows as the square. This is the birthday bound, after the same effect in the birthday problem.

<Note>

Strong collision resistance is the property that matters when an attacker controls both messages, as in forging a signed message. Weak collision resistance suffices when one message is fixed by an honest party.

</Note>

## OAEP

Optimal Asymmetric Encryption Padding. A randomised padding applied to a message before RSA encryption.

It is a 2-round Feistel network over the message $M$ and a random seed $r$, with round functions built from a hash $H$:

- $\text{maskedM} = (M \,\|\, \text{padding}) \oplus G(r)$, where $G$ expands $r$ to the block width.
- $\text{maskedR} = r \oplus H(\text{maskedM})$.
- The RSA input is $\text{maskedM} \,\|\, \text{maskedR}$.

Effects:

- Randomised
  The same $M$ encrypts differently each run through $r$.
- All-or-nothing
  Every output bit depends on every bit of $M$ and $r$, so a tampered block fails the padding check on decryption.

This makes RSA encryption secure against chosen-ciphertext attacks. The hash is used only as padding, so no collision property is relied on.
