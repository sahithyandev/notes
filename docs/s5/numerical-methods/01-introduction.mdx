Numerical methods are algorithms that produce approximate numerical solutions to mathematical problems, used when an exact analytical solution doesn't exist or is too costly to compute.

## Sources of Error

### Round-Off Error

The error from representing real numbers with finite precision on a computer.

Arises because most real numbers can't be stored exactly in a fixed number of digits, so every arithmetic operation carries a small representation error.

### Truncation Error

The error from approximating an infinite or continuous process with a finite one.

Arises when a method replaces an exact mathematical operation, such as a limit, an infinite series, or a derivative, with a finite approximation.

<Note>

Round-off error grows with more computation steps. Truncation error shrinks as the approximation is refined. Choosing a method balances the 2.

</Note>

## Worked Example

Approximate $e^{0.5}$ using the first 3 terms of its Maclaurin series. Then find the round-off error from storing $\sqrt{2}$ with 4 significant digits.

<Solution>

Truncation error

$$
e^{0.5} \approx 1 + 0.5 + \frac{0.5^2}{2!} = 1.625
$$

The exact value is $e^{0.5} = 1.64872$, so

$$
E_{\text{trunc}} = 1.64872 - 1.625 = 0.02372
$$

Adding the next term $\dfrac{0.5^3}{3!} = 0.02083$ shrinks the error to $0.00289$.

Round-off error

$\sqrt{2} = 1.41421\ldots$ is stored as $1.414$.

$$
E_{\text{round}} = |\sqrt{2} - 1.414| = 0.00021
$$

Squaring the stored value gives

$$
1.414^2 = 1.999396
$$

so the representation error of $0.00021$ becomes an error of $6.04 \times 10^{-4}$ in the result.

</Solution>
