A nonlinear system of $n$ equations in $n$ unknowns $x_1, x_2, \ldots, x_n$ is a set of equations of the form

$$
\begin{aligned}
f_1(x_1, x_2, \ldots, x_n) &= 0 \\
f_2(x_1, x_2, \ldots, x_n) &= 0 \\
&\;\vdots \\
f_n(x_1, x_2, \ldots, x_n) &= 0
\end{aligned}
$$

where each $f_i$ maps a vector $\vec{x} = (x_1, x_2, \ldots, x_n)^T \in \mathbb{R}^n$ into $\mathbb{R}$.

In vector form, $F(\vec{x}) = \vec{0}$, where

$$
F(\vec{x}) = \big(f_1(\vec{x}), f_2(\vec{x}), \ldots, f_n(\vec{x})\big)^T
$$

Here:

<Symbols>
  <Sym s="F">
    maps $\mathbb{R}^n$ into $\mathbb{R}^n$
  </Sym>
  <Sym s="f_1, f_2, \ldots, f_n">coordinate functions of $F$</Sym>
</Symbols>

## Continuity from Bounded Partials

<Theorem>

Let $f$ be a function from $D \subseteq \mathbb{R}^n$ into $\mathbb{R}$ and $\vec{x}_0 \in D$. Suppose all partial derivatives of $f$ exist, and constants $\delta > 0$ and $K > 0$ exist so that whenever $\|\vec{x} - \vec{x}_0\| < \delta$ and $\vec{x} \in D$,

$$
\left| \frac{\partial f(\vec{x})}{\partial x_j} \right| \le K, \quad j = 1, 2, \ldots, n
$$

Then $f$ is continuous at $\vec{x}_0$.

</Theorem>

## Methods

Numerical methods for solving nonlinear systems generalize the single-variable case.

### Fixed-Point Iteration

Rewrites $F(\vec{x}) = \vec{0}$ as $\vec{x} = G(\vec{x})$, then iterates $\vec{x}^{(k)} = G(\vec{x}^{(k-1)})$. See fixed point.

### Newton's Method

Uses the [Jacobian matrix](/s2/methods-of-mathematics/multivariable-calculus/jacobian#jacobian-matrix) of $F$ to get quadratic convergence to a root of $F(\vec{x}) = \vec{0}$. See Newton's method.

## Worked Examples

### Example 1

Place the system

$$
\begin{aligned}
3x_1 - \cos(x_2 x_3) - \tfrac{1}{2} &= 0 \\
x_1^2 - 81(x_2 + 0.1)^2 + \sin x_3 + 1.06 &= 0 \\
e^{-x_1 x_2} + 20x_3 + \tfrac{10\pi - 3}{3} &= 0
\end{aligned}
$$

in the form $F(\vec{x}) = \vec{0}$, and verify that $\vec{p} = \left(0.5, 0, -\tfrac{\pi}{6}\right)^T$ is a solution.

<Solution>

The coordinate functions are

$$
\begin{aligned}
f_1(x_1, x_2, x_3) &= 3x_1 - \cos(x_2 x_3) - \tfrac{1}{2} \\
f_2(x_1, x_2, x_3) &= x_1^2 - 81(x_2 + 0.1)^2 + \sin x_3 + 1.06 \\
f_3(x_1, x_2, x_3) &= e^{-x_1 x_2} + 20x_3 + \tfrac{10\pi - 3}{3}
\end{aligned}
$$

so $F(\vec{x}) = \big(f_1(\vec{x}), f_2(\vec{x}), f_3(\vec{x})\big)^T$. Evaluating at $\vec{p} = \left(0.5, 0, -\tfrac{\pi}{6}\right)^T$ gives

$$
\begin{aligned}
f_1(\vec{p}) &= 3(0.5) - \cos(0) - \tfrac{1}{2} = 1.5 - 1 - 0.5 = 0 \\
f_2(\vec{p}) &= (0.5)^2 - 81(0.1)^2 + \sin\!\left(-\tfrac{\pi}{6}\right) + 1.06 = 0.25 - 0.81 - 0.5 + 1.06 = 0 \\
f_3(\vec{p}) &= e^{0} + 20\!\left(-\tfrac{\pi}{6}\right) + \tfrac{10\pi - 3}{3} = 1 - \tfrac{10\pi}{3} + \tfrac{10\pi}{3} - 1 = 0
\end{aligned}
$$

Thus $F(\vec{p}) = \vec{0}$.

</Solution>

### Example 2

Place the system

$$
\begin{aligned}
x_1^2 + x_2^2 &= 4 \\
x_1^2 - x_2 &= 2
\end{aligned}
$$

in the form $F(\vec{x}) = \vec{0}$ and find all real solutions.

<Solution>

Moving all terms to the left gives $F(\vec{x}) = \big(f_1(\vec{x}), f_2(\vec{x})\big)^T = \vec{0}$ with

$$
\begin{aligned}
f_1(x_1, x_2) &= x_1^2 + x_2^2 - 4 \\
f_2(x_1, x_2) &= x_1^2 - x_2 - 2
\end{aligned}
$$

From $f_2(x_1, x_2) = 0$, $x_1^2 = x_2 + 2$. Substituting into $f_1(x_1, x_2) = 0$ gives

$$
x_2^2 + x_2 - 2 = (x_2 + 2)(x_2 - 1) = 0 \implies x_2 = -2 \text{ or } x_2 = 1
$$

- For $x_2 = -2$, $x_1^2 = 0 \implies x_1 = 0$, giving $(0, -2)^T$.
- For $x_2 = 1$, $x_1^2 = 3 \implies x_1 = \pm\sqrt{3}$, giving $(\sqrt{3}, 1)^T$ and $(-\sqrt{3}, 1)^T$.

The system has 3 real solutions, $(0, -2)^T$, $(\sqrt{3}, 1)^T$, and $(-\sqrt{3}, 1)^T$. Unlike a linear system, a nonlinear system can have any finite number of solutions.

</Solution>

### Example 3

Show that $f(x_1, x_2) = x_1^2 + \cos(x_1 x_2)$ is continuous at $\vec{x}_0 = (1, 0)^T$ using the bounded-partials theorem.

<Solution>

The partial derivatives are

$$
\frac{\partial f}{\partial x_1} = 2x_1 - x_2 \sin(x_1 x_2), \quad \frac{\partial f}{\partial x_2} = -x_1 \sin(x_1 x_2)
$$

Take $\delta = 1$. Whenever $\|\vec{x} - \vec{x}_0\|_\infty < 1$, the coordinates satisfy $0 < x_1 < 2$ and $-1 < x_2 < 1$, so $|\sin(x_1 x_2)| \le 1$ gives

$$
\left|\frac{\partial f(\vec{x})}{\partial x_1}\right| \le 2|x_1| + |x_2||\sin(x_1 x_2)| < 2(2) + 1(1) = 5
$$

$$
\left|\frac{\partial f(\vec{x})}{\partial x_2}\right| \le |x_1||\sin(x_1 x_2)| < 2(1) = 2
$$

Both partial derivatives are bounded by $K = 5$ on $\|\vec{x} - \vec{x}_0\|_\infty < 1$, so $f$ is continuous at $(1, 0)^T$.

</Solution>
