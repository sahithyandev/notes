Equivalent systems are the systems with the same set of solutions.

2 linear systems are equivalent **iff** one is obtained from the other by a finite number of [elementary operations](/s1/mathematics/matrices/elementary-transformations).

<Note title="Proof Hint">

- Show a single elementary operation preserves the solution set (case by case on the 3 operation types)
- Extend to a finite chain of elementary operations by induction

</Note>

Applying elementary operations to the augmented matrix $[A \mid \vec{b}]$ instead of the equations gives row equivalence (see Elementary Transformations).

## Row-Equivalent Matrix

2 matrices are said to be row-equivalent **iff** one can be obtained from the other by a finite number of [elementary row operations](/s1/mathematics/matrices/elementary-transformations).
