Gauss elimination fails or degrades in 2 cases:

- Division by zero  
  The pivot element $a_{ii}^{(i)} = 0$, so the normalization step is undefined.
- Round-off error growth  
  The pivot element is small compared to the other entries in its column.

## Partial pivoting

Before normalizing row $l$, find the largest available coefficient in the column below the pivot and swap it into the pivot position.

If the pivot $a_{ll}^{(l)}$ is small relative to the entries below it in the same column, find the smallest $p \ge l$ such that

$$
|a_{pl}^{(l)}| = \max_{l \le i \le n} |a_{il}^{(l)}|
$$

and perform $R_l \leftrightarrow R_p$.

<Note>

Searching both rows and columns for the largest element is called complete pivoting. It's rarely used since switching columns changes the order of the $x_i$'s and adds significant complexity.

</Note>

## Scaled partial pivoting

Used when pivot magnitudes are small relative to other entries in their own row, not just their column.

Let $t_i = \max_{1 \le j \le n} |a_{ij}|$. If $t_i \neq 0$, select the row $R_p$, $p \ge i$, with

$$
\max_{i \le k \le n} \frac{|a_{ki}|}{t_k}
$$

and perform $R_i \leftrightarrow R_p$ if $i \neq p$.

<Note>

If $t_i = 0$ for some $i$, the system has no unique solution since the entire $i$-th row is $0$.

</Note>

Examples:

Apply scaled partial pivoting to

$$
\begin{aligned}
30.00x_1 + 591400x_2 &= 591700 \\
5.291x_1 - 6.130x_2 &= 46.78
\end{aligned}
$$

$$
t_1 = \max\{|30.00|, |591400|\} = 591400, \quad t_2 = \max\{|5.291|, |6.130|\} = 6.130
$$

$$
\frac{|a_{11}|}{t_1} = \frac{30}{591400} = 5.073 \times 10^{-5}, \quad \frac{|a_{21}|}{t_2} = \frac{5.291}{6.130} = 0.8631
$$

$\dfrac{|a_{21}|}{t_2}$ is larger, so exchange $R_1 \leftrightarrow R_2$. Gauss elimination on the reordered system gives $x_1 = 10.00$ and $x_2 = 1.000$.
