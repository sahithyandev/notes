## WWW Architecture

The architecture of the Web is separate from the code that implements it.

- There is no single piece of code that implements the Web's architecture.
- Multiple pieces of code implement different components of the architecture.
- For example, different web browsers implement parts of the Web architecture.
- The Web's architectural constraints are not directly visible in the code.
- The effects of these constraints can be observed in the Web.

## Pipe and Filter Architecture

The **Pipe and Filter** architectural style consists of filters connected through pipes.

A filter takes a stream of data as input, processes it, and produces a stream of data as output.

A pipe connects two filters by routing the output of one filter to the input of another.

## Genres of Architecture

- **Enterprise Architecture**  
  Defines the overall structure of an organization, including its business, systems, and technology.

- **System of Systems Architecture**  
  Describes how multiple independent systems work together as a larger system.

- **Systems Architecture**  
  Defines the structure and interaction of the major components of a complete system.

- **Software Architecture**  
  Defines the structure of a software system, including its major software elements and their relationships.

## Commonalities Between Architecture Genres

All architecture genres involve:

- Satisfying functional and quality attributes.
- Evaluating the architecture for suitability.
- Documenting and communicating the architecture.
- Using the architecture as a blueprint for construction and development.

## Activities for All Architecture Genres

The main activities include:

- Understanding goals, context, and requirements.
- Architecture creation, evaluation, and documentation.
- Managing the architecture after creation through evolution.
- Assisting in post-architecture activities such as maintenance, conformance, and performance analysis.

## Software Architecture and Other Genres

- Enterprise architecture and system architecture provide an environment in which software lives.
- They provide requirements and constraints to which software architecture must adhere.
- Elements of these architectures may contain software architecture, but neither substitutes for software architecture.
- Software and system architectures are critical for ensuring that the system meets its business and mission goals.
- Each system in a **System of Systems (SoS)** has system and software architectures.
