## Why Analyze Architectures?

**Architecture analysis** evaluates a software architecture to understand important properties of the system.

It can reveal important system properties even before the system is implemented.

### Benefits of Architecture Analysis

- **Early understanding** Identifies important properties of the system before implementation.
- **Economic benefit** Helps identify architectural problems before they become expensive to fix.
- **Architecture evaluation** Should be a standard part of every architecture-based development methodology.

## When to Analyze Architectures?

Architecture evaluation is most cost-effective when performed as early as possible in the system's life cycle.

However, evaluation can also be carried out at different stages throughout the system's life cycle.

### Comparing Competing Architectures

Architecture analysis can help select between two competing architectures.

The process involves:

1. Evaluating both architectures.
2. Comparing their results against the required criteria.
3. Selecting the architecture that performs better against those criteria.

The objective is to determine which architecture is more suitable for the system's requirements.

## Architecture Evaluation

Architecture evaluation examines whether an architecture satisfies the required criteria.

There are some terms **evaluation**, **assessment**, and **validation** when discussing architecture evaluation techniques.

These techniques help stakeholders examine architectural decisions and understand their implications.

## Evaluation Techniques

1. Presentations
2. Formal Reviews and Structured Walkthroughs
3. Evaluation Using Scenarios
4. Prototypes and Proof-of-Concept Systems
5. Skeleton Systems

Each technique provides a different way to evaluate an architecture.

The techniques differ in their depth of analysis, purpose, and implementation effort.
