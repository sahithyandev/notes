## Evolution of Computing

Computing has evolved through six paradigms, from centralized mainframe systems to cloud computing.

1. Mainframe Computing
2. PC Computing
3. Network Computing
4. Internet Computing
5. Grid Computing
6. Cloud Computing

## Mainframe Computing

**Mainframe computing** uses a centralized mainframe computer to provide computing resources to users through terminals.

The mainframe performs the main processing tasks.

## PC Computing

**PC computing** uses personal computers to perform computing tasks locally.

Computing resources are available on individual computers rather than being provided entirely by a centralized mainframe.

## Network Computing

**Network computing** connects computers through a network and allows them to communicate with servers.

Computers can access resources and services provided by other machines.

## Internet Computing

**Internet computing** uses the Internet to connect users and servers across networks.

Users can access remote applications and services through Internet connections.

## Grid Computing

**Grid computing** connects multiple computing resources to work together on computational tasks.

It allows distributed resources to contribute to a larger computing workload.

## Cloud Computing

**Cloud computing** provides access to computing resources through a cloud environment.

Generally cloud computing as the next stage in the evolution of computing paradigms.

## Summary of Computing Paradigms

| Paradigm                | Main Idea                                                                  |
| ----------------------- | -------------------------------------------------------------------------- |
| **Mainframe Computing** | Centralized computing through a mainframe and terminals.                   |
| **PC Computing**        | Computing performed on personal computers.                                 |
| **Network Computing**   | Computers communicate and access resources through networks.               |
| **Internet Computing**  | Users access remote servers and services through the Internet.             |
| **Grid Computing**      | Distributed computing resources work together on tasks.                    |
| **Cloud Computing**     | Computing resources and services are provided through a cloud environment. |
