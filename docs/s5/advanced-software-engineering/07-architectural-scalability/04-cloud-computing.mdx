## Introduction to Cloud Computing

**Cloud computing** provides computing resources and services through a cloud environment.

Cloud computing as an evolution of computing that enables users to access computing resources and services without relying entirely on their own physical infrastructure.

Cloud providers and services associated with application delivery, web services, infrastructure, and data backup.

## Cloud Service Models

### Software as a Service (SaaS)

**SaaS** provides software applications as services through the cloud.

Users access the application without having to manage the underlying infrastructure themselves.

### Platform as a Service (PaaS)

**PaaS** provides a platform on which applications can be developed and deployed.

It offers services and components that support application development.

### Infrastructure as a Service (IaaS)

**IaaS** provides infrastructure resources through the cloud.

These resources include computing, storage, networking, and related infrastructure capabilities.

### Comparison of Cloud Service Models

| Service Model | Main Purpose                                                                  |
| ------------- | ----------------------------------------------------------------------------- |
| **SaaS**      | Provides software applications as services.                                   |
| **PaaS**      | Provides a platform for developing and deploying applications.                |
| **IaaS**      | Provides infrastructure resources such as computing, storage, and networking. |

These models as layers: the application cloud builds on the service cloud, which builds on the infrastructure cloud.

## Cloud Deployment Models

| Deployment Model    | Description                                                                   |
| ------------------- | ----------------------------------------------------------------------------- |
| **Private Cloud**   | A cloud environment intended for a particular organization.                   |
| **Community Cloud** | A cloud environment shared by a community of organizations with common needs. |
| **Public Cloud**    | A cloud environment offered for use by customers through a provider.          |
| **Hybrid Cloud**    | A combination of multiple cloud environments.                                 |

## Essential Characteristics of Cloud Computing

### On-Demand Self-Service

Users can obtain computing resources when required without needing direct human interaction with the service provider for every request.

### Broad Network Access

Cloud services are available over a network and can be accessed through different client devices.

### Resource Pooling

The provider pools computing resources to serve multiple users.

Resources can be assigned and reassigned according to demand.

### Rapid Elasticity

Resources can be increased or decreased rapidly according to workload requirements.

The available capacity can therefore adapt to changing demand.

### Measured Service

Resource usage is measured so that service utilization can be monitored.

## Cloud Computing Foundation

Identifies several foundational technologies and concepts that enable cloud computing.

- Virtualization
- Distributed computing
- Autonomic systems
- Grid technology
- Broadband networks
- Web 2.0
- Service-oriented architectures
- Free and open-source software
- Web application frameworks
- Browser as a platform
- Service-level agreements
- Utility computing

These technologies and concepts contribute to the infrastructure and service capabilities of cloud computing.

## Cloud Computing Characteristics

The NIST framework also identifies common characteristics of cloud computing.

| Characteristic              | Description                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| **Massive Scale**           | Cloud environments can operate at a large scale.                                         |
| **Resilient Computing**     | Cloud environments are designed to support continued operation despite certain failures. |
| **Homogeneity**             | Resources may use standardized or similar technologies.                                  |
| **Geographic Distribution** | Resources can be distributed across different locations.                                 |
| **Virtualization**          | Physical resources can be represented as virtual resources.                              |
| **Service Orientation**     | Capabilities are provided as services.                                                   |
| **Low-Cost Software**       | The framework identifies low-cost software as a common characteristic.                   |
| **Advanced Security**       | Security is an important characteristic of cloud environments.                           |

## Balancing IT Architecture and Operations

It presents a framework for balancing customer control and supplier control against the level of automation.

The framework compares four approaches.

| Approach                    | Control and Responsibility                               | Operating Style                    |
| --------------------------- | -------------------------------------------------------- | ---------------------------------- |
| **Traditional IT**          | Greater customer control, ownership, and responsibility. | Scheduled, physical, and manual.   |
| **Traditional Outsourcing** | Greater supplier control, ownership, and responsibility. | Scheduled, physical, and manual.   |
| **Private Cloud**           | Greater customer control, ownership, and responsibility. | On-demand, virtual, and automated. |
| **Public Cloud**            | Greater supplier control, ownership, and responsibility. | On-demand, virtual, and automated. |

The framework illustrates how cloud computing changes the way computing resources are provided and managed.

## Summary

Cloud computing combines service delivery models, deployment models, and enabling technologies to provide computing resources through the cloud.

- **Service models:** SaaS, PaaS, and IaaS.
- **Deployment models:** Private, Community, Public, and Hybrid Cloud.
- **Essential characteristics:** On-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service.
- **Foundational technologies:** Virtualization, distributed computing, grid technology, and service-oriented architectures.
