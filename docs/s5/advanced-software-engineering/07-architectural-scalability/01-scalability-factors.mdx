## Scalability

**Scalability** refers to the number of users, sessions, transactions, or operations that an entire system can perform.

A scalable architecture should support increasing workloads while considering performance, availability, cost, and maintenance effort.

## Factors Affecting Scalability

Identifies the following scalability factors.

| Factor                 | Description                                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Scalability**        | Number of users, sessions, transactions, or operations the entire system can perform.                                      |
| **Performance**        | Optimal utilization of resources.                                                                                          |
| **Responsiveness**     | Time taken to complete an operation.                                                                                       |
| **Availability**       | Probability that the application, or a portion of it, is available at a given point in time.                               |
| **Downtime Impact**    | Impact of a server, service, or resource being unavailable, including the number of users affected and the type of impact. |
| **Cost**               | Cost associated with the system and its resources.                                                                         |
| **Maintenance Effort** | Effort required to maintain the system.                                                                                    |

## Understanding the Factors

### Scalability and Performance

**Scalability** concerns how much work the system can handle.

**Performance** concerns how efficiently the system uses its resources.

A system may handle more users after adding resources, but the resulting performance depends on how effectively those resources are utilized.

### Responsiveness

Responsiveness measures the time required to perform an operation.

For example, when a user requests a web page, responsiveness concerns how long the user waits for the page to load.

### Availability and Downtime Impact

Availability describes the likelihood that the system is operational when needed.

Downtime impact describes the consequences when a server, service, or resource becomes unavailable.

These factors are related but different. Two systems may experience downtime with different consequences for their users.

### Cost and Maintenance Effort

Scalability decisions also involve financial and operational considerations.

Adding hardware, distributing services, and managing additional nodes can affect both the cost of the system and the effort required to maintain it.
