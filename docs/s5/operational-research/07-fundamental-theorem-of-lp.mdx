For a linear program in standard form with a non-empty, bounded feasible region:

- If a feasible solution exists, a basic feasible solution exists.
- If an optimal feasible solution exists, an optimal basic feasible solution exists.

This is why the simplex algorithm only needs to search among basic feasible solutions (extreme points of the feasible polyhedron) rather than the entire feasible region.
