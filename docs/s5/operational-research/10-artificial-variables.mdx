A $\ge$ or $=$ constraint has no slack/surplus variable that alone forms an identity column, so an artificial variable is added to give the simplex algorithm a starting basic feasible solution.

An artificial variable has no meaning in the original problem. A valid final solution must have every artificial variable equal to 0 (non-basic or basic at value 0).

Removing artificial variables from the basis before optimality is checked is needed because the algorithm otherwise reports an infeasible problem as feasible. 2 methods handle this:

- Big-M method
- Two-phase method
