Resource management assigns limited resources to project activities while preserving precedence relationships and the required project completion date.

The [project network](/s5/operational-research/project-network) supplies the durations, earliest times, latest times, and floats used in the schedule.

## Three Different Tasks

| Task       | Question                              | What changes                                  |
| ---------- | ------------------------------------- | --------------------------------------------- |
| Scheduling | When can each activity run?           | Creates the initial timetable                 |
| Leveling   | Is any resource over its limit?       | Moves activities until the limit is satisfied |
| Smoothing  | Can the workload be made less uneven? | Moves activities within their floats          |

Use the methods in this order.

1. Schedule activities at their earliest feasible starts.
2. Calculate resource demand in every interval.
3. Level the schedule if demand exceeds capacity.
4. Smooth the feasible schedule if peaks and idle periods remain.

<Note>

Leveling is a capacity problem. Smoothing is a workload-shape problem.

</Note>

## Resource Profile

For resource $r$, the demand in time period $t$ is

$$
R_{r,t} = \sum_{i \in A_t} r_i
$$

<Symbols>
  <Sym s="A_t">activities running during time period $t$</Sym>
  <Sym s="r_i">amount of resource $r$ required by activity $i$</Sym>
  <Sym s="R_{r,t}">total demand for resource $r$ during time period $t$</Sym>
</Symbols>

Create the profile by splitting the timeline at every activity start and finish. Add the resources of the activities running in each interval.

An activity contributes from its start up to, but not including, its finish. A dummy activity contributes $0$ resources.

## Scheduling

1. List every activity, duration, predecessor, and resource requirement.
2. Apply the forward and backward passes to the project network.
3. Place every activity at its earliest start.
4. Calculate the resource profile.
5. Compare every demand with the available capacity.

Activities with positive total float are candidates for movement. Critical activities have zero total float and normally remain fixed.

## Leveling

Leveling removes over-allocation. The resource capacity is a ceiling that no interval may cross.

### Quick Leveling Method

1. Find the first interval where demand exceeds capacity.
2. List the activities running in that interval.
3. Remove critical activities from the candidate list.
4. Choose a candidate with enough float to move.
5. Prefer the move that removes the most excess with the least loss of float.
6. Move the activity to its latest feasible start.
7. Recalculate the affected intervals.
8. Repeat until no interval exceeds capacity.

Check these 3 conditions after every move.

- Precedence \
  Every predecessor still finishes before the activity starts.
- Capacity \
  No resource demand exceeds its available capacity.
- Completion \
  The new project finish is recorded.

Leveling may extend the project when available float is insufficient. A move within existing float does not extend the project.

## Smoothing

Smoothing reduces variation in a schedule that already satisfies capacity. It does not change activity durations, precedence relationships, or the project completion date.

Think of the resource profile as bars.

- Leveling removes bars above a fixed ceiling.
- Smoothing moves bars away from peaks and into valleys.

The goal is not a perfectly constant profile. The goal is fewer avoidable peaks and idle intervals.

### Quick Smoothing Method

1. Start with a feasible, leveled schedule.
2. Find a high-demand interval and a nearby low-demand interval.
3. Find an activity crossing the high-demand interval with positive float.
4. Shift it toward the low-demand interval.
5. Keep the shift if the project finish is unchanged and the profile improves.
6. Repeat until no useful shift remains.

## Worked Example

Resource $R$ has a capacity of $3$ units per time period.

| Activity | Duration | Predecessor | Resource $R$ |
| -------- | -------: | ----------- | -----------: |
| $A$      |        4 | none        |            1 |
| $B$      |        3 | none        |            1 |
| $C$      |        2 | $A$         |            1 |
| $D$      |        0 | $B$         |            0 |
| $E$      |        5 | $B$         |            2 |
| $F$      |        3 | $C$, $D$    |            3 |
| $G$      |        4 | $E$         |            0 |

The project duration is $12$. The critical path is $B \to E \to G$.

Prepare the earliest-start schedule. Level the resource use. Then smooth the leveled schedule.

<Solution>

### 1. Earliest-Start Schedule

| Activity | Start | Finish | Float |
| -------- | ----: | -----: | ----: |
| $A$      |     0 |      4 |     3 |
| $B$      |     0 |      3 |     0 |
| $C$      |     4 |      6 |     3 |
| $D$      |     3 |      3 |     6 |
| $E$      |     3 |      8 |     0 |
| $F$      |     6 |      9 |     3 |
| $G$      |     8 |     12 |     0 |

The resource profile is:

| Interval | Running activities | Demand |
| -------- | ------------------ | -----: |
| $0$–$3$  | $A$, $B$           |    $2$ |
| $3$–$4$  | $A$, $E$           |    $3$ |
| $4$–$6$  | $C$, $E$           |    $3$ |
| $6$–$8$  | $E$, $F$           |    $5$ |
| $8$–$9$  | $F$                |    $3$ |
| $9$–$12$ | none               |    $0$ |

The interval $6$–$8$ is overloaded. Its demand is $5$, but capacity is $3$.

### 2. Level the Schedule

Only $E$ and $F$ run during the overload. $E$ is critical. $F$ has float $3$.

Move $F$ from $6$–$9$ to $9$–$12.

The new profile is:

| Interval | Running activities | Demand |
| -------- | ------------------ | -----: |
| $0$–$3$  | $A$, $B$           |    $2$ |
| $3$–$4$  | $A$, $E$           |    $3$ |
| $4$–$6$  | $C$, $E$           |    $3$ |
| $6$–$8$  | $E$                |    $2$ |
| $8$–$9$  | none               |    $0$ |
| $9$–$12$ | $F$                |    $3$ |

No interval exceeds capacity. The project still finishes at $12$. This is leveling.

### 3. Smooth the Leveled Schedule

The leveled profile still has an empty interval at $8$–$9$. Activity $A$ has float $3$.

Move $A$ from $0$–$4$ to $3$–$7. Its successor $C$ moves from $4$–$6$ to $7$–$9.

The smoothed profile is:

| Interval | Running activities | Demand |
| -------- | ------------------ | -----: |
| $0$–$3$  | $B$                |    $1$ |
| $3$–$7$  | $A$, $E$           |    $3$ |
| $7$–$8$  | $C$, $E$           |    $3$ |
| $8$–$9$  | $C$                |    $1$ |
| $9$–$12$ | $F$                |    $3$ |

The project still finishes at $12$. Capacity is still satisfied. The empty interval is gone. This is smoothing.

</Solution>
