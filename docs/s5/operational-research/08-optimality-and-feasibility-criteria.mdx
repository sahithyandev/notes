Criteria used by the simplex algorithm to test a basic feasible solution at each iteration.

## Feasibility Criterion

The right-hand-side (RHS) value of every basic variable must be $\ge 0$. Used to select the leaving variable via the minimum ratio test, keeping the next solution feasible.

## Optimality Criterion

For a maximization problem in standard form, every objective row coefficient must be $\ge 0$. A negative coefficient means the corresponding non-basic variable can enter the basis and improve the objective further.

For a minimization problem, the criterion flips: every objective row coefficient must be $\le 0$.
