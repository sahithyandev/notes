Convert a linear program to standard form before applying the simplex algorithm.

- Objective should be maximization  
  Negate the objective if it's a minimization problem.
- Constraints must be equalities  
  All inequalities are converted using slack, surplus, or artificial variables.
- Variables must be non-negative

## Slack Variable

A non-negative variable added to a $\le$ constraint. Absorbs unused capacity, converting it to an equality.

## Surplus Variable

A non-negative variable subtracted from a $\ge$ constraint. Absorbs excess over the minimum, converting it to an equality.

## Artificial Variable

A non-negative variable added to a $\ge$ or $=$ constraint. Provides a starting basic feasible solution when slack or surplus alone can't.
