Any artefact added to an image at any stage of acquisition, storage or processing is noise.

- Includes random changes and deterministic changes, including side-effects of other processing
- Can affect individual pixels or larger regions
- Some noise is visible, some is not perceptible
- Often modeled probabilistically, since noise is usually embedded within image detail

<Note>

Total absence of noise can make an image look artificial. Noise is also a natural phenomenon.

</Note>
