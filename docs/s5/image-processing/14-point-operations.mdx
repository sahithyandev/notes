Point operations modify the intensity of a pixel using only that pixel's own value, in isolation from its neighbours. May use statistical data relating to other pixels, such as the image histogram.

Homogeneous **iff** the operation is independent of pixel location.

## Lookup Table

A lookup table (LUT) maps the current pixel value to an index, returning a new value from the table.

- Enables on the fly processing, especially on hardware platforms
- Changing table content changes the operation without changing any code

Examples:

- Pseudo colouring, e.g. mapping thermal image temperature to RGB
- Compensating for non-linearity in sensor elements

## Grey Level Histogram

The grey level histogram shows the frequency of occurrence of each intensity level in an image, regardless of pixel position. Its shape describes overall brightness and contrast.

Normalized histogram:

$$
P(k) = \frac{N(k)}{n}
$$

Here:

<Symbols>
  <Sym s="N(k)">number of pixels with intensity $k$</Sym>
  <Sym s="n">total number of pixels</Sym>
</Symbols>

Defines the probability of intensity level $k$ in the image.

Accumulated histogram:

$$
A(k) = \sum_{j \le k} P(j)
$$

Defines the accumulated probability of pixels with intensity level $\le k$.

### Characteristics

- Position independent  
  The histogram ignores where pixels are. Rearranging the pixels leaves it unchanged, so different images can share one histogram.
- Size independent  
  The normalized histogram holds proportions, so images of different sizes can be compared.
- Sums to 1  
  $\sum_k P(k) = 1$. The accumulated histogram never decreases and reaches 1 at the highest level.
- Gives mean and spread  
  Brightness is the mean and contrast is the standard deviation of the distribution.

$$
\mu = \sum_k k\,P(k) \qquad \sigma^2 = \sum_k (k - \mu)^2 P(k)
$$

Here:

<Symbols>
  <Sym s="\mu">mean intensity</Sym>
  <Sym s="\sigma^2">variance of intensity</Sym>
</Symbols>

| Shape                       | Meaning                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------ |
| Concentrated at low levels  | Dark image.                                                                                      |
| Concentrated at high levels | Bright image.                                                                                    |
| Narrow                      | Low contrast.                                                                                    |
| Wide                        | High contrast.                                                                                   |
| 2 separated peaks           | Objects and background with different intensities. A threshold between the peaks separates them. |

Effect of a point operation on the histogram:

- A one-to-one mapping moves bins without changing their heights.
- A many-to-one mapping merges bins and adds their heights. The merged levels cannot be told apart afterwards.
- No point operation splits a bin, since all pixels with the same input level get the same output level. So a histogram can only be approximated, and unused levels appear as gaps.

### Brightness and Contrast

Brightness and contrast are the position and the width of the same histogram. Both are described as point operations mapping input intensity $r$ to output intensity $s$.

- Brightness  
  Mean intensity. A shift $s = r + c$ slides the histogram along the intensity axis, keeping its shape and width.
- Contrast  
  Spread of intensities. Histogram width, the gap between the darkest and brightest points, measures it. A gain $s = a r$ stretches the histogram wider.

Here:

<Symbols>
  <Sym s="r">input intensity</Sym>
  <Sym s="s">output intensity</Sym>
  <Sym s="c">shift constant, added to move brightness</Sym>
  <Sym s="a">gain constant, multiplied to change contrast</Sym>
</Symbols>

Shifting the histogram changes brightness only. Every pair of pixels keeps the same intensity gap, so contrast is unaffected.

<Note>

Auto-focus algorithms maximize the standard deviation of pixel intensities, which measures contrast.

- Sharp image  
  Neighbouring pixels differ a lot. Intensities spread widely, so the standard deviation is large.
- Blurred image  
  Each pixel is averaged with its neighbours. Intensities move closer together, so the standard deviation is small.

Blur does not change the mean intensity. It moves light between pixels and does not add or remove any.

</Note>

## Point Processing Functions

Common transformations applied to each pixel, typically implemented as a LUT mapping input intensity $r$ to output intensity $s$.

| Function                                                                                                                                                                                            | Equation                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Identity<br />Output equals input.                                                                                                                                                                  | $s = r$                                                                                                                                                                                             |
| Digital negative<br />Inverts intensity.                                                                                                                                                            | $s = (L-1) - r$                                                                                                                                                                                     |
| Square root<br />Compresses bright values and expands dark ones. $c = \sqrt{L-1}$ maps the top level to itself.                                                                                     | $s = c\sqrt{r}$                                                                                                                                                                                     |
| Contrast stretching<br />Piecewise linear expansion of a chosen intensity range.                                                                                                                    | $s = \begin{cases} \dfrac{s_1}{r_1}\,r & 0 \le r < r_1 \\ s_1 + \dfrac{s_2 - s_1}{r_2 - r_1}(r - r_1) & r_1 \le r \le r_2 \\ s_2 + \dfrac{L-1-s_2}{L-1-r_2}(r - r_2) & r_2 < r \le L-1 \end{cases}$ |
| Normalizing<br />Rescales intensities to use the full available range.                                                                                                                              | $s = (L-1)\,\dfrac{r - r_{\min}}{r_{\max} - r_{\min}}$                                                                                                                                              |
| Clipping<br />Forces values outside a chosen range to the range boundary.                                                                                                                           | $s = \begin{cases} a & r < a \\ r & a \le r \le b \\ b & r > b \end{cases}$                                                                                                                         |
| Intensity level slicing<br />Highlights a chosen intensity band, suppressing all others.                                                                                                            | $s = \begin{cases} L-1 & a \le r \le b \\ 0 & \text{otherwise} \end{cases}$                                                                                                                         |
| Bit slicing<br />Extracts bit-plane $k$ of the pixel value. The result is $0$ or $1$.                                                                                                               | $s = \left\lfloor \dfrac{r}{2^k} \right\rfloor \bmod 2$                                                                                                                                             |
| Range stretching or compression<br />Maps a chosen input range onto a different output range. It stretches when the output range is wider than the input range, and compresses when it is narrower. | $s = s_{\min} + (s_{\max} - s_{\min})\,\dfrac{r - r_{\min}}{r_{\max} - r_{\min}}$                                                                                                                   |
| Histogram equalization<br />Redistributes intensities to make the histogram more uniform.                                                                                                           | $s = \operatorname{round}\big((L-1)\,A(r)\big)$                                                                                                                                                     |

Here:

<Symbols>
  <Sym s="L">number of grey levels</Sym>
  <Sym s="a, b">lower and upper bounds of the chosen range</Sym>
  <Sym s="c">scaling constant</Sym>
  <Sym s="(r_1, s_1), (r_2, s_2)">
    control points of the piecewise linear curve
  </Sym>
  <Sym s="r_{\min}, r_{\max}">limits of the input range</Sym>
  <Sym s="s_{\min}, s_{\max}">limits of the output range</Sym>
  <Sym s="k">bit-plane index, with $0$ the least significant bit</Sym>

Normalizing is range stretching with the output range $[0, L-1]$ and the input range set to the image minimum and maximum.

## Histogram Matching

<Aka>histogram specification</Aka>. The process of adjusting a test image so its
grey level distribution follows a given reference distribution.

The reference is supplied as a 256-element array holding the reference CDF, one value per grey level.

Procedure:

- Compute the test image histogram, then its CDF $C_t$
- For each test level $g$, find the reference level $r$ whose CDF value $C_r(r)$ is closest to $C_t(g)$
- Store $g \mapsto r$ in a 256-entry LUT
- Apply the LUT to every pixel

$$
\text{LUT}(g) = \arg\min_{r} \, \lvert C_r(r) - C_t(g) \rvert
$$

Here:

<Symbols>
  <Sym s="C_t(g)">accumulated probability of test level $\le g$</Sym>
  <Sym s="C_r(r)">accumulated probability of reference level $\le r$</Sym>
</Symbols>

Histogram equalization is the special case where the reference CDF is linear. Matching 2 levels through equal CDF values preserves their relative ordering.

For a colour image, each channel is matched independently against the reference channel.

<Note>

A good reference image gives a smooth reference CDF. A test level can only map to reference levels that the reference image actually contains, so gaps in the reference histogram appear as gaps in the output.

</Note>

```python
def cdf(pixels):
    # count how many pixels have each intensity
    hist = [0] * 256
    for v in pixels:
        hist[v] += 1
    # accumulate the counts and divide by the total to get the CDF
    total = len(pixels)
    running, out = 0, [0.0] * 256
    for i, c in enumerate(hist):
        running += c
        out[i] = running / total
    return out

def match(test_pixels, ref_cdf):
    ct = cdf(test_pixels)
    # build the LUT: for each test level g, pick the reference
    # level r whose CDF value is closest to the test CDF value
    lut = [0] * 256
    for g in range(256):
        best_r = 0
        best_diff = abs(ref_cdf[0] - ct[g])
        for r in range(1, 256):
            diff = abs(ref_cdf[r] - ct[g])
            if diff < best_diff:
                best_diff = diff
                best_r = r
        lut[g] = best_r
    # remap every pixel through the LUT
    out = []
    for v in test_pixels:
        out.append(lut[v])
    return out
```

For a colour image, match each channel against that channel's reference CDF.

### Multiple Images and Histograms

Each image has its own $C_t$, so every image needs its own LUT. The reference CDF is the only input shared between images.

- 1 reference for all images  
  Compute the reference CDF once, then build and apply one LUT per image. All outputs follow the same distribution, so brightness and contrast are consistent across the set.
- 1 reference per image  
  Pair each image with its reference CDF, then match each pair separately.
- References not paired with images  
  Give each image the reference whose CDF is closest, then match.

The distance between an image $i$ and a reference $j$ is the total absolute difference of their CDFs.

$$
d(i, j) = \sum_{g} \lvert C_{t,i}(g) - C_{r,j}(g) \rvert
$$

Image $i$ takes the reference $\arg\min_j d(i, j)$. When each reference may be used by only 1 image, solve an assignment problem on the matrix $d(i, j)$, for example with the Hungarian algorithm.

```python
def match_to_closest(images, ref_cdfs):
    out = []
    for pixels in images:
        ct = cdf(pixels)
        # pick the reference whose CDF differs least from the image CDF
        best = min(ref_cdfs, key=lambda rc: sum(abs(a - b) for a, b in zip(ct, rc)))
        out.append(match(pixels, best))
    return out
```

## Worked Example

Match a 4-pixel test image to a reference CDF over 4 grey levels $\{0, 1, 2, 3\}$.

Test pixels: $0, 1, 1, 3$.

Test histogram: $[1, 2, 0, 1]$, total $4$.

Test CDF $C_t$: $[0.25, 0.75, 0.75, 1.0]$.

Reference CDF $C_r$: $[0.1, 0.2, 0.7, 1.0]$.

<Solution>

Mapping:

- $g = 0$, $C_t = 0.25$: closest is $C_r(1) = 0.2$, so $0 \mapsto 1$
- $g = 1$, $C_t = 0.75$: closest is $C_r(2) = 0.7$, so $1 \mapsto 2$
- $g = 2$, $C_t = 0.75$: $2 \mapsto 2$
- $g = 3$, $C_t = 1.0$: $C_r(3) = 1.0$, so $3 \mapsto 3$

Output pixels: $1, 2, 2, 3$.

</Solution>
