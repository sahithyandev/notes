Let $S \subseteq \mathbb{C}$ be the domain of a complex function $f$.

## Mapping Extensions

For the definition of a complex function and its mapping notation, see the [S1 complex-function mapping section](/s1/mathematics/complex-analysis/introduction#complex-functions-as-mappings).

- The inverse image of a point $\omega$ is the set of all $z$ in the domain of $f$ with $f(z) = \omega$.

<Note>

Translation, rotation, and reflection describe the dominant geometric characteristics of mappings. The $z$-plane and $\omega$-plane are treated as the same plane in these cases.

</Note>

Examples:

- $\omega = z+1$ translates each point $z$ one unit to the right.
- $\omega = z+i$ translates each point $z$ one unit upwards.
- $\omega = e^{i\theta}$ rotates each point $z$ through an angle $\theta$ about the origin, counterclockwise, since $e^{i\theta} = \cos\theta + i\sin\theta$.
- $\omega = iz$ rotates each non-zero point $z$ through a 90 degree angle about the origin, counterclockwise, since $i = e^{i\pi/2}$.
- $\omega = \bar{z}$ reflects each point $z$ about the real axis.
- $\omega = -z$ reflects each point $z$ about the imaginary axis.

## Neighborhood

A neighborhood of $z_0$ is any set containing $D_r(z_0)$ for some $r > 0$.

$D_r(z_0)$ is the open disk of radius $r$ centered at $z_0$.

$$
D_r(z_0) = \{z \in \mathbb{C} : |z-z_0| < r\}
$$

### Deleted Neighborhood

<Aka>punctured neighborhood</Aka>. A deleted neighborhood of $z_0$ is a
neighborhood with $z_0$ removed. The deleted disk of radius $r$ is

$$
D_r(z_0) \setminus \{z_0\} = \{z \in \mathbb{C} : 0 < |z-z_0| < r\}
$$

## Open Set

A set $G \subseteq \mathbb{C}$ is open **iff** every point of $G$ has a neighborhood contained in $G$.

## Domain

A domain is an open set that is [connected](/s5/calculus/vector-valued-functions/connectedness#connected-region).

## Limit Point

Let $D \subseteq \mathbb{C}$ and $z_0 \in \mathbb{C}$. $z_0$ is a limit point of $D$ **iff** every deleted neighborhood of $z_0$ contains at least 1 point of $D$.

$z_0$ is a limit point of $D$ **iff**

$$
\forall r > 0,\ \big(D_r(z_0) \setminus \{z_0\}\big) \cap D \neq \varnothing
$$

A limit point of $D$ need not belong to $D$.

## Isolated Point

Let $D \subseteq \mathbb{C}$ and $z_0 \in D$. $z_0$ is an isolated point of $D$ **iff** $z_0$ is not a limit point of $D$. Equivalently, some deleted neighborhood of $z_0$ contains no point of $D$.

$z_0$ is an isolated point of $D$ **iff**

$$
z_0 \in D \text{ and } \exists r > 0,\ \big(D_r(z_0) \setminus \{z_0\}\big) \cap D = \varnothing
$$

This is the same as $D_r(z_0) \cap D = \{z_0\}$ for some $r > 0$.

Otherwise the point is a non-isolated point of $D$. It is a limit point of $D$ that belongs to $D$.

## Worked Example

Let $D = \{0\} \cup \{1/n : n \in \mathbb{N}\}$. Classify $0$, $1$, and $2$ as limit points or isolated points of $D$.

<Solution>

$0$ is a limit point because every disk centered at $0$ contains $1/n$ for sufficiently large $n$.

$1$ is an isolated point. For example, $D_{1/4}(1) \cap D = \{1\}$.

$2$ is neither a limit point nor a point of $D$. The disk $D_{1/2}(2)$ contains no point of $D$.

</Solution>
