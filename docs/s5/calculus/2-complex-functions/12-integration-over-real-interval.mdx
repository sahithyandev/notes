Let $f(t) = u(t) + iv(t)$ for $a \le t \le b$, where $u$ and $v$ are real-valued continuous functions of the real variable $t$.

$$
\int_a^b f(t)\,\text{d}t = \int_a^b u(t)\,\text{d}t + i\int_a^b v(t)\,\text{d}t
$$

If $U'(t) = u(t)$ and $V'(t) = v(t)$ for each $a \le t \le b$,

$$
\int_a^b f(t)\,\text{d}t = (U(b) - U(a)) + i(V(b) - V(a))
$$

## Properties

Let $f(t) = u(t) + iv(t)$ and $g(t) = p(t) + iq(t)$ be continuous on $[a,b]$.

- $\displaystyle\int_a^b (f(t) + g(t))\,\text{d}t = \int_a^b f(t)\,\text{d}t + \int_a^b g(t)\,\text{d}t$
- $\displaystyle\int_a^b f(t)\,\text{d}t = \int_a^c f(t)\,\text{d}t + \int_c^b f(t)\,\text{d}t$, for $a \le c \le b$
- $\displaystyle\int_a^b \alpha f(t)\,\text{d}t = \alpha \int_a^b f(t)\,\text{d}t$, for a complex constant $\alpha$
- $\displaystyle\int_a^b f(t)\,\text{d}t = -\int_b^a f(t)\,\text{d}t$
- $\displaystyle\int_a^b f'(t)\,\text{d}t = f(b) - f(a)$, when $f$ is continuously differentiable on $[a,b]$
- $\displaystyle\int_a^b f(t)g(t)\,\text{d}t = \int_a^b (u p - v q)\,\text{d}t + i\int_a^b (u q + v p)\,\text{d}t$
