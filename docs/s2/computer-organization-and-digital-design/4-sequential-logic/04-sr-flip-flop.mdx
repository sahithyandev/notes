Has 2 inputs: $S$ and $R$, and 2 outputs: $Q$ and $\overline{Q}$.

| S   | R   | Q         | Q'        | Description              |
| --- | --- | --------- | --------- | ------------------------ |
| 0   | 0   | No Change | No Change | Holds the previous state |
| 0   | 1   | 0         | 1         | Resets the output to 0   |
| 1   | 0   | 1         | 0         | Sets the output to 1     |
| 1   | 1   | Undefined | Undefined | Invalid state            |

| 0                 | 1               | 1   | 0   |
| 1                 | 0               | 0   | 1   |
